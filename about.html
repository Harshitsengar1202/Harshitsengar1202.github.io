I'm Harshit Sengar, a Data Engineer at Tata Consultancy Services, working with big data, streaming, and distributed processing technologies to build reliable pipelines and analytics solutions. My work centers on turning raw, high-volume data into usable insights through efficient ETL and processing workflows.

That experience strengthened my fundamentals in backend systems, microservices, and scalable application design before I transitioned into data engineering.

I work with PySpark, Apache Spark, Python, SQL, Kafka, and data warehousing concepts to build robust data pipelines and modern analytics infrastructure. I enjoy solving real-world data problems and continuously learning the tools that shape the next generation of data platforms.
